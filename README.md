# Codebase Q&A

A RAG system over Sentry's source code with AST-aware chunking, hybrid retrieval, contextual retrieval, and cross-encoder reranking.

## Status

Work in progress. Built over a weekend as a learning project.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # then fill in your Groq API key
```
